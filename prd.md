## 1. Кратко о продукте

Veroniks — карманный парфюмерный клуб в Telegram. Пользователь может:

- найти аромат в библиотеке и отфильтровать её по признакам;
- посмотреть пирамиду нот и описание;
- найти ароматы, похожие на любимый;
- описать словами, чего хочется, и получить подбор от советника.

Атмосфера — закрытый британский джентльменский клуб в духе фильмов Гая Ричи: твид, кожа, латунь, виски, сухая ирония.

## 2. Проблема

- Информация о ароматах разбросана по разным источникам. Fragrantica перегружена и неудобна на телефоне.
- Сложно найти замену любимому аромату (дешевле, мягче, «то же, но на лето»).
- Новичку трудно перевести желание («хочу тёплое и уютное») на язык нот и аккордов.

## 3. Цели

| Цель | Как поймём, что достигнута |
|---|---|
| Быстрый подбор аромата | От открытия бота до рекомендации — не больше 30 секунд |
| Удобный каталог на телефоне | Любой аромат находится поиском или фильтрами за 3 касания |
| Полезные «похожие» | Для известных ароматов в топе — узнаваемые аналоги (Aventus → Club de Nuit Intense Man) |
| Работа без затрат на ИИ | MVP полностью работает без ключа API |
| Удовольствие от стиля | Друзья пользуются повторно и показывают другим |

**Не цели (вне рамок v1):** продажа парфюмерии, отзывы и рейтинги от пользователей, монетизация, парсинг Fragrantica, публичный доступ для всех.

## 4. Пользователи

| Персона | Описание | Главный сценарий |
|---|---|---|
| **Любитель** | Знает несколько ароматов, хочет расширить коллекцию | «Найди похожее на мой любимый» |
| **Новичок** | Не разбирается в нотах, ищет первый «свой» аромат | «Хочу что-то свежее для офиса» |
| **Даритель** | Выбирает подарок | «Подарок мужу, он любит древесные, на зиму» |
| **Знаток** | Разбирается в нотах | Фильтр «содержит ирис, без уда», изучение пирамид |

Доступ — только по белому списку Telegram ID (владелец и друзья).

## 5. Пользовательские истории

1. Как пользователь, я хочу открыть приложение одной кнопкой из бота, чтобы не устанавливать ничего отдельно.
2. Как пользователь, я хочу искать аромат по названию, бренду или ноте.
3. Как пользователь, я хочу фильтровать каталог по семейству, полу, сезону, поводу, аккордам, а также «с нотой» и «без ноты».
4. Как пользователь, я хочу видеть пирамиду нот (верх, сердце, база) и понятное описание аромата.
5. Как пользователь, я хочу ввести любимый аромат и получить похожие с процентом совпадения и общими нотами.
6. Как пользователь, я хочу описать словами желание и получить 3–5 рекомендаций с объяснением.
7. Как пользователь, я хочу сохранять ароматы в избранное и в «мой гардероб».
8. Как пользователь, я хочу спросить бота прямо в чате (`/similar Aventus`), не открывая приложение.
9. Как пользователь, я хочу поделиться карточкой аромата с другом ссылкой.
10. Как владелец, я хочу, чтобы бот отвечал только моим друзьям.

## 6. Функциональные требования

### 6.1. Библиотека ароматов
- Поиск по названию, бренду и нотам с автодополнением.
- Фильтры: семейство, пол, сезон, повод, аккорды, «содержит ноту», «без ноты».
- Сортировка: по рейтингу, по году, по алфавиту.
- Бесконечная прокрутка.

**Критерий приёмки:** поиск по базе в 20 000+ ароматов отвечает быстрее 300 мс; фильтры комбинируются.

### 6.2. Карточка-«досье»
- Название, бренд, год, пол, семейство.
- Визуальная пирамида: треугольник из трёх ярусов (верх, сердце, база) с нотами рядом.
- Полосы аккордов с весами.
- Теги сезона и повода.
- Описание: 2–3 предложения в стиле персоны.
- Кнопки: «Похожие», «В избранное», «Поделиться», «Открыть на Fragrantica».

**Критерий приёмки:** пирамида читается на экране 360 px без горизонтальной прокрутки.

### 6.3. Похожие ароматы
- Поле ввода с автодополнением.
- Топ-10 похожих с % совпадения и списком общих нот.
- Алгоритм:
  - взвешенный Жаккар по нотам (база ×2, сердце ×1.5, верх ×1);
  - плюс косинусная близость аккордов;
  - плюс небольшой бонус за совпадение семейства.

**Критерий приёмки:** для Aventus в топ-5 есть Club de Nuit Intense Man; результат появляется быстрее 500 мс.

### 6.4. Советник
**v1 — движок правил, без ИИ:**
- Разбор запроса на русском: словарь из 150+ выражений → ноты, аккорды, семейства, сезон, пол, повод.
- Учёт отрицаний: «не слишком сладкий», «без уда».
- Распознавание запросов «как X» → поиск похожих.
- Ответ: 3–5 ароматов, к каждому — объяснение через совпавшие ноты.
- Если запрос непонятен — уточняющий вопрос с кнопками-вариантами.
- Быстрые подсказки: «На свидание», «В офис», «Зимний вечер», «Похожее на…».

**v2 — ИИ (когда появится ключ API):**
- Тот же интерфейс советника.
- LLM выбирает только из кандидатов в базе и возвращает id и обоснования.
- Включается автоматически, если в `.env` заполнен `ANTHROPIC_API_KEY`.

**Критерий приёмки:** на запрос «тёплое, дымное, на зимний вечер, не слишком сладкое» советник рекомендует подходящие ароматы и не предлагает гурманские бомбы.

### 6.5. Избранное и гардероб
- Хранение: Telegram CloudStorage, если приложение открыто в Telegram, иначе localStorage.
- Два списка: «Избранное» (хочу попробовать) и «Мой гардероб» (уже есть).

### 6.6. Telegram-бот @veroniksparfbot

| Команда | Действие |
|---|---|
| `/start` | Приветствие в стиле персоны + кнопка «Войти в клуб» (Mini App) |
| `/similar <название>` | Топ-5 похожих текстом |
| `/perfume <название>` | Пирамида и описание + кнопка «Открыть в приложении» |
| Свободный текст | Ответ советника прямо в чате |

- Кнопка меню открывает Mini App.
- Deep link на карточку: `startapp=p_<id>`.
- Посторонним — вежливый отказ в стиле персоны.

## 7. Данные

**Источник — гибрид:**
1. Kaggle-датасет (выгрузка Fragrantica) в формате CSV. Импортируется один раз скриптом в SQLite.
2. Встроенный seed из ~50 известных ароматов, чтобы приложение работало до импорта.
3. Ссылка «Открыть на Fragrantica» у каждого аромата.

Описания пишутся своими словами: в v1 их собирает шаблонный генератор, в v2 — LLM.

**Ограничение:** Fragrantica не парсится. Это запрещено правилами сайта, и он защищён от ботов.

**Модель данных `Perfume`:**

| Поле | Тип | Пример |
|---|---|---|
| id | string | `creed-aventus` |
| name / brand / year | string / string / number | Aventus / Creed / 2010 |
| gender | male / female / unisex | male |
| family | string | шипровые фруктовые |
| accords | [{name, weight}] | фруктовый 0.9, древесный 0.7 |
| notesTop / notesHeart / notesBase | string[] | ананас, бергамот… |
| seasons / occasions | string[] | весна, лето / день, офис |
| rating / votes | number | 4.3 / 25 000 |
| description | string | 2–3 предложения |
| fragranticaUrl | string | ссылка |

Ноты хранятся отдельной таблицей со связью «аромат–нота–ярус». Действует словарь перевода ~300 нот на русский и синонимов.

## 8. Дизайн

**Настроение:** закрытый британский клуб, загородное поместье, твид, кожа, виски, латунь. Только атмосфера: без логотипов, кадров, названий, персонажей и шрифтов сериала.

| Токен | Цвет |
|---|---|
| Racing green (фон) | `#14231B` / `#1E3328` |
| Латунь (акцент) | `#C9A45C` |
| Бордо | `#6E1F1F` |
| Кремовая бумага (карточки) | `#EFE6D2` |
| Тёмная кожа | `#2A1D16` |

- **Шрифты:** Playfair Display или Cormorant Garamond для заголовков, Inter для текста, моноширинный для меток «досье». У всех есть кириллица.
- **Элементы:** лёгкая фактура твида, латунные рамки, тиснение, карточки как клубные досье, гербовая монограмма «V».
- **Навигация:** нижняя панель — Советник / Библиотека / Похожие / Избранное.
- **Анимации:** пирамида раскрывается снизу вверх, карточки появляются плавно; учитывается `prefers-reduced-motion`.

**Голос (персона советника):** сдержанный британский джентльмен-парфюмер, владелец клуба Veroniks. Сухая ирония, уверенность, лёгкая дерзость, без грубости. Говорит коротко и по-русски.
> Пример: «Тёплое и дымное на зимний вечер? Сэр, у меня для вас камин в флаконе».

## 9. Техническая архитектура

```
Telegram ──► @veroniksparfbot (grammY) ──┐
                                         ├──► Сервер (Node.js + Fastify) ──► SQLite
Telegram Mini App / браузер (PWA) ───────┘          │
   (React + Vite + TS)                              └──► [v2] Anthropic API
```

- **Монорепо:** `/web`, `/server`, `/shared` (типы, похожесть, советник, описания), `/scripts` (импорт CSV).
- **Безопасность:** проверка Telegram initData (HMAC), белый список `ALLOWED_USER_IDS`, rate limit, секреты только в `.env`.
- **Запуск:**
  - разработка — `npm run dev` + HTTPS-туннель cloudflared на компьютере владельца;
  - постоянно — Docker на Render или Railway, бот через webhook.

**Переменные окружения:** `BOT_TOKEN`, `WEBAPP_URL`, `ALLOWED_USER_IDS`, `DATABASE_PATH`, `ANTHROPIC_API_KEY` (необязательно), `ANTHROPIC_MODEL` (необязательно).

## 12. Метрики успеха (для себя)

- Не менее 5 друзей пользуются хотя бы раз в неделю.
- Не менее 60% рекомендаций советника кажутся «в точку» (проверка по ощущениям на 20 тестовых запросах).
- Похожие ароматы совпадают с мнением сообщества на 10 известных примерах.
